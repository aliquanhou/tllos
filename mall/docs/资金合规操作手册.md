## 一、资金流转概述

### 1.1 资金流转路径

```
用户支付 → 第三方支付渠道（微信/支付宝）→ 平台账户 → 商家结算 → 商家提现 → 商家银行账户
```

### 1.2 资金状态说明

| 状态 | 说明 | 可操作 |
|------|------|--------|
| 在途 | 用户已支付，订单未完成 | 不可结算 |
| 可结算 | 订单已完成，进入结算周期 | 可生成结算单 |
| 已结算 | 结算单已确认，资金进入商家可用余额 | 可提现 |
| 冻结中 | 商家申请提现，资金冻结 | 等待审核打款 |
| 已提现 | 提现已打款 | 流程完成 |

### 1.3 平台抽成规则

- 默认抽成比例：**5%**
- 可在后台配置：`/payment/config` → `platform_commission_rate`
- 计算公式：
  - 平台抽成 = 订单金额 × 抽成比例
  - 商家应收 = 订单金额 - 平台抽成
  - 商家净收入 = 商家应收 - 退款金额

## 二、支付管理操作

### 2.1 查看支付记录

**API**: `GET /payment/query`

**查询参数**:
- `id`: 支付记录 ID（可选）
- `payment_no`: 支付单号（可选）

**返回字段**:
- `payment_no`: 支付单号
- `order_id`: 订单 ID
- `order_no`: 订单号
- `user_id`: 用户 ID
- `amount`: 支付金额
- `pay_method`: 支付方式（wechat/alipay/balance）
- `pay_status`: 支付状态（pending/paid/failed/refunded）
- `transaction_id`: 第三方交易号
- `paid_at`: 支付时间
- `refund_amount`: 已退款金额
- `refund_status`: 退款状态（none/partial/full）

### 2.2 支付配置管理

**查看配置**: `GET /payment/config`

**更新配置**: `PUT /payment/config`

**配置项说明**:

| 配置键 | 说明 | 默认值 |
|--------|------|--------|
| `wechat_appid` | 微信支付 AppID | wx_your_appid |
| `wechat_mch_id` | 微信支付商户号 | your_mch_id |
| `wechat_api_v3_key` | 微信支付 APIv3 密钥 | your_api_v3_key |
| `wechat_sandbox` | 微信支付沙箱模式 | true |
| `alipay_app_id` | 支付宝 AppID | your_alipay_app_id |
| `alipay_sandbox` | 支付宝沙箱模式 | true |
| `platform_commission_rate` | 平台抽成比例 | 0.05 |
| `auto_settle_days` | 自动结算天数 | 7 |

### 2.3 沙箱模式说明

- **沙箱模式**: `wechat_sandbox=true` / `alipay_sandbox=true`
- **用途**: 开发测试，不产生真实资金流转
- **模拟支付**: `POST /payment/sandbox/pay`
- **上线前**: 必须配置真实商户号和密钥，并关闭沙箱模式

## 三、退款操作

### 3.1 发起退款

**API**: `POST /payment/refund`

**请求参数**:
```json
{
  "order_id": 123,
  "amount": 50.00,
  "reason": "用户申请退货"
}
```

**说明**:
- `order_id`: 订单 ID（必填）
- `amount`: 退款金额（可选，默认全额退款）
- `reason`: 退款原因（可选）

**退款规则**:
- 支持部分退款
- 退款金额不能超过订单金额 - 已退款金额
- 余额支付：实时退回用户余额
- 微信/支付宝支付：调用第三方退款接口，资金原路返回

### 3.2 退款状态

| 状态 | 说明 |
|------|------|
| `pending` | 退款申请已提交，等待处理 |
| `success` | 退款成功 |
| `failed` | 退款失败 |

## 四、商家结算操作

### 4.1 结算周期

- 默认结算周期：**7 天**（订单完成后 7 天可结算）
- 可配置：`auto_settle_days`

### 4.2 生成结算单

结算单包含以下信息：
- 结算周期（开始日期 - 结束日期）
- 订单总数
- 订单总金额
- 平台抽成
- 商家应收
- 退款金额
- 商家净收入

### 4.3 查看结算单

**API**: `GET /payment/settlements`

**查询参数**:
- `merchant_id`: 商家 ID（可选）
- `status`: 结算状态（可选）

**结算状态**:
| 状态 | 说明 |
|------|------|
| `pending` | 待确认 |
| `settled` | 已结算 |

### 4.4 确认结算

**API**: `POST /payment/settlement/confirm`

**请求参数**:
```json
{
  "id": 123
}
```

确认结算后，资金进入商家可用余额。

## 五、商家提现操作

### 5.1 商家余额说明

| 字段 | 说明 |
|------|------|
| `available_balance` | 可用余额（可提现） |
| `frozen_balance` | 冻结余额（提现申请中） |
| `total_income` | 累计收入 |
| `total_withdrawal` | 累计提现 |

**查询余额**: `GET /payment/merchant/balance?merchant_id=1`

### 5.2 申请提现

**API**: `POST /payment/withdrawal/apply`

**请求参数**:
```json
{
  "merchant_id": 1,
  "amount": 1000.00,
  "bank_name": "中国工商银行",
  "bank_account": "6222021234567890123",
  "account_name": "张三"
}
```

**提现规则**:
- 提现金额不能超过可用余额
- 提现手续费：**1%**（默认）
- 实际到账金额 = 提现金额 - 手续费
- 申请后资金冻结，等待审核

### 5.3 提现审核

**API**: `POST /payment/withdrawal/audit`

**请求参数**:
```json
{
  "id": 123,
  "approved": true,
  "remark": "审核通过"
}
```

**审核结果**:
- `approved=true`: 审核通过，扣减冻结余额，等待打款
- `approved=false`: 审核拒绝，解冻资金，退回可用余额

### 5.4 标记打款

**API**: `POST /payment/withdrawal/paid`

**请求参数**:
```json
{
  "id": 123,
  "payment_proof": "银行转账凭证号"
}
```

### 5.5 提现状态

| 状态 | 说明 |
|------|------|
| `pending` | 待审核 |
| `approved` | 审核通过，待打款 |
| `rejected` | 审核拒绝 |
| `paid` | 已打款 |

### 5.6 查看提现记录

**API**: `GET /payment/withdrawals`

**查询参数**:
- `merchant_id`: 商家 ID（可选）
- `status`: 提现状态（可选）

## 七、财务对账流程

### 7.1 每日对账

1. 导出当日支付记录：`GET /payment/query`
2. 导出当日退款记录
3. 与第三方支付渠道对账（微信/支付宝对账单）
4. 核对资金流水台账：`GET /payment/account-logs`
5. 确认差异并处理

### 7.2 每月结算

1. 生成月度结算单
2. 核对商家订单金额、平台抽成、退款金额
3. 确认结算单：`POST /payment/settlement/confirm`
4. 处理商家提现申请
5. 导出月度财务报表

### 7.3 异常处理

| 异常 | 处理方式 |
|------|----------|
| 支付成功但订单未更新 | 检查回调日志，手动更新订单状态 |
| 退款失败 | 检查第三方支付渠道，重新发起退款 |
| 结算金额不符 | 核对订单明细，调整结算单 |
| 提现打款失败 | 检查银行账户信息，重新打款 |

## 八、合规注意事项

### 8.1 支付合规

- 必须使用持牌支付机构（微信支付、支付宝）
- 不得自建资金池，资金必须通过持牌机构清算
- 支付回调必须验签，防止伪造回调
- 保留完整的支付记录和交易凭证

### 8.2 结算合规

- 商家结算周期不得超过 30 天
- 结算单必须可查询、可导出
- 平台抽成比例必须公开透明
- 不得无故拖延商家结算

### 8.3 提现合规

- 商家提现必须实名认证
- 大额提现需要人工审核
- 提现记录必须完整保存
- 不得向非法账户转账

### 8.4 数据留存

- 支付记录：至少保存 5 年
- 资金流水：至少保存 5 年
- 结算单：至少保存 5 年
- 提现记录：至少保存 5 年

## 九、常见问题

### Q1: 如何开启真实支付？
A: 配置微信/支付宝商户号和密钥，将 `wechat_sandbox` 和 `alipay_sandbox` 设置为 `false`。

### Q2: 如何修改平台抽成比例？
A: 调用 `PUT /payment/config`，更新 `platform_commission_rate` 配置项。

### Q3: 商家提现多久到账？
A: 审核通过后，财务人员手动打款，一般 1-3 个工作日到账。

### Q4: 如何导出财务报表？
A: 通过 API 查询支付记录、结算单、资金流水，然后导出为 Excel。

### Q5: 退款多久到账？
A: 余额支付实时到账；微信/支付宝支付 1-3 个工作日原路返回。
