# TLLOS 商城 - ICP备案与经营资质操作指南

**版本**: v1.0
**日期**: 2026-09-04
**适用对象**: 运营人员、法务人员

## 一、ICP备案概述

### 1.1 什么是ICP备案

ICP备案是指在中国境内提供非经营性互联网信息服务，应当依法履行备案手续。

**法律依据**:
- 《互联网信息服务管理办法》（国务院令第292号）
- 《非经营性互联网信息服务备案管理办法》（信息产业部令第33号）

**备案要求**:
- 所有在中国境内服务器上运行的网站都必须进行ICP备案
- 未备案的网站不得在中国境内服务器上运行
- 备案信息必须真实、准确、完整

### 1.2 ICP备案类型

| 类型 | 适用范围 | 审批机构 | 有效期 |
|------|----------|----------|--------|
| **非经营性ICP备案** | 个人/企业网站、博客、论坛等 | 工信部（各省通信管理局） | 长期（需定期核验） |
| **经营性ICP许可证** | 电商平台、在线支付、有偿信息服务等 | 工信部（各省通信管理局） | 5年（到期需续期） |

### 1.3 TLLOS商城备案类型判断

**业务模式**: B2B2C 多商户电商平台
- 平台提供商品展示、在线交易、支付结算等服务
- 平台向商家收取佣金/服务费
- 用户可在线购买商品并支付

**结论**:
- **必须进行非经营性ICP备案**（所有网站都需要）
- **建议申请经营性ICP许可证**（涉及在线交易和有偿服务）

## 二、非经营性ICP备案操作

### 2.1 备案前准备

**所需材料**:

| 材料 | 说明 | 个人 | 企业 |
|------|------|------|------|
| 身份证 | 负责人身份证正反面 | ✅ | ✅ |
| 营业执照 | 企业营业执照副本 | ❌ | ✅ |
| 域名证书 | 域名注册证书 | ✅ | ✅ |
| 服务器信息 | 服务器IP、服务商 | ✅ | ✅ |
| 网站名称 | 网站备案名称 | ✅ | ✅ |
| 网站负责人 | 负责人姓名、电话、邮箱 | ✅ | ✅ |
| 核验照片 | 负责人在指定背景前的照片 | ✅ | ✅ |

**域名要求**:
- 域名必须已注册
- 域名注册信息必须与备案主体一致
- 域名必须解析到备案的服务器IP

**服务器要求**:
- 服务器必须在中国境内
- 服务器服务商必须有IDC/ISP资质
- 服务器IP必须固定

### 2.2 备案流程

**步骤1：选择服务器服务商**
- 推荐：阿里云、腾讯云、华为云、百度云等
- 服务商提供备案系统和备案服务

**步骤2：登录备案系统**
- 阿里云：https://beian.aliyun.com
- 腾讯云：https://cloud.tencent.com/product/icp
- 华为云：https://www.huaweicloud.com/product/icp.html

**步骤3：填写备案信息**
- 主体信息（个人/企业）
- 网站信息（网站名称、域名、服务内容）
- 负责人信息（姓名、电话、邮箱）
- 服务器信息（IP、服务商）

**步骤4：上传材料**
- 身份证正反面
- 营业执照（企业）
- 域名证书
- 核验照片（部分服务商需要）

**步骤5：提交审核**
- 服务商初审（1-3个工作日）
- 通信管理局审核（5-20个工作日）
- 审核通过后发放备案号

**步骤6：备案号展示**
- 在网站底部展示备案号
- 备案号链接到工信部备案查询网站
- 链接地址：https://beian.miit.gov.cn

### 2.3 备案信息填写规范

**网站名称**:
- 个人网站：可以使用个人名称、博客名称等
- 企业网站：建议使用企业名称或品牌名称
- 不得使用"中国"、"中华"、"国家"等字样（除非有授权）
- 不得使用敏感词汇

**网站服务内容**:
- 电商平台：选择"网上购物"或"电子商务"
- 企业官网：选择"企业官网"
- 个人博客：选择"博客"或"个人空间"

**负责人信息**:
- 负责人必须是备案主体的法定代表人或授权人员
- 电话必须真实有效（会进行电话核验）
- 邮箱必须真实有效

### 2.4 备案常见问题

**Q1: 备案需要多长时间？**
A: 一般需要 7-20 个工作日，具体取决于各省通信管理局的审核速度。

**Q2: 备案期间网站可以访问吗？**
A: 不可以。备案期间网站必须关闭，否则会被驳回。

**Q3: 备案号如何展示？**
A: 在网站底部添加备案号，并链接到 https://beian.miit.gov.cn。例如：
```html
<a href="https://beian.miit.gov.cn" target="_blank">粤ICP备XXXXXXXX号</a>
```

**Q4: 备案信息变更怎么办？**
A: 登录备案系统，提交变更申请，审核通过后生效。

**Q5: 备案可以转移吗？**
A: 可以。如果更换服务器服务商，需要办理备案转移手续。

## 三、经营性ICP许可证申请

### 3.1 什么是经营性ICP许可证

经营性ICP许可证是指在中国境内提供经营性互联网信息服务，应当依法取得的许可证。

**法律依据**:
- 《互联网信息服务管理办法》（国务院令第292号）
- 《电信业务经营许可管理办法》（工业和信息化部令第42号）

**适用范围**:
- 电子商务平台（涉及在线交易和支付）
- 有偿信息服务（付费会员、付费内容）
- 在线广告服务
- 其他经营性互联网信息服务

### 3.2 申请条件

| 条件 | 要求 |
|------|------|
| **主体资质** | 依法设立的公司（内资企业，外资受限） |
| **注册资本** | 不少于100万元人民币（省网）/ 1000万元（全网） |
| **人员要求** | 至少3名员工缴纳社保（部分省份要求更多） |
| **技术能力** | 有从事互联网信息服务的专业人员和技术方案 |
| **场地要求** | 有固定的办公场所 |
| **信誉要求** | 最近3年内无重大违法违规记录 |
| **网站要求** | 网站已完成非经营性ICP备案 |

### 3.3 申请材料

1. **营业执照副本**（复印件加盖公章）
2. **公司章程**（加盖工商查询章）
3. **验资报告或审计报告**（最近一期）
4. **法人身份证**（复印件）
5. **主要管理人员身份证**（至少3人）
6. **社保证明**（至少3人，最近1个月）
7. **域名注册证书**
8. **服务器托管协议或租赁合同**
9. **网站备案证明**
10. **业务发展和实施计划**
11. **技术方案**（网络拓扑、安全措施等）
12. **信息安全保障措施**
13. **依法经营承诺书**

### 3.4 申请流程

**步骤1：准备材料**
- 按照上述清单准备所有材料
- 确保材料真实、准确、完整

**步骤2：登录申请系统**
- 工信部电信业务市场综合管理系统：https://ythzxfw.miit.gov.cn
- 注册账号并登录

**步骤3：填写申请信息**
- 企业基本信息
- 业务类型（选择"信息服务业务（ICP）"）
- 业务覆盖范围（省网/全网）
- 网站信息

**步骤4：上传材料**
- 按照系统要求上传所有材料
- 确保材料清晰、完整

**步骤5：提交审核**
- 省通信管理局初审（5-10个工作日）
- 专家评审（如需）
- 审批决定（20-60个工作日）

**步骤6：领取许可证**
- 审批通过后，领取《增值电信业务经营许可证》
- 许可证有效期5年，到期需续期

### 3.5 经营性ICP许可证与非经营性ICP备案的区别

| 对比项 | 非经营性ICP备案 | 经营性ICP许可证 |
|--------|------------------|------------------|
| **性质** | 备案（告知性） | 许可（审批性） |
| **适用范围** | 非经营性网站 | 经营性网站 |
| **审批机构** | 省通信管理局 | 省通信管理局/工信部 |
| **申请条件** | 无特殊要求 | 注册资本100万+、3人社保等 |
| **有效期** | 长期（需核验） | 5年（需续期） |
| **费用** | 免费 | 免费（但需满足条件） |
| **审批时间** | 7-20个工作日 | 20-60个工作日 |

## 四、其他相关资质

### 4.1 公安备案

**什么是公安备案**:
- 公安机关对互联网信息服务进行的备案
- 依据《计算机信息网络国际联网安全保护管理办法》

**备案要求**:
- 所有网站都需要进行公安备案
- 备案后获得公安备案号
- 在网站底部展示公安备案号

**备案流程**:
1. 登录全国互联网安全管理服务平台：https://www.beian.gov.cn
2. 注册账号并登录
3. 填写网站信息
4. 上传材料
5. 提交审核
6. 审核通过后获得公安备案号

**展示方式**:
```html
<a href="http://www.beian.gov.cn" target="_blank">
  <img src="公安备案图标" alt="公安备案">
  粤公网安备 XXXXXXXXXXXXX号
</a>
```

### 4.2 支付业务许可证

**什么是支付业务许可证**:
- 中国人民银行颁发的支付业务许可证
- 从事支付业务必须取得的许可证

**TLLOS商城是否需要**:
- **不需要**。TLLOS商城使用微信支付、支付宝等持牌支付机构，不自行从事支付业务。
- 如未来需要自建支付系统，则需要申请支付业务许可证。

### 4.3 食品经营许可证

**适用范围**:
- 销售食品类商品（预包装食品、散装食品、保健食品等）
- 提供餐饮服务

**申请要求**:
- 有固定的经营场所
- 有相应的设备设施
- 有食品安全管理人员
- 有食品安全管理制度

**申请机构**: 当地市场监督管理局

### 4.4 医疗器械经营许可证

**适用范围**:
- 销售第二类、第三类医疗器械
- 第一类医疗器械不需要许可证，但需要备案

**申请要求**:
- 有相应的经营场所和储存条件
- 有相应的质量管理人员
- 有相应的质量管理制度

**申请机构**: 当地药品监督管理局

### 4.5 出版物经营许可证

**适用范围**:
- 销售图书、报纸、期刊、音像制品、电子出版物等

**申请要求**:
- 有固定的经营场所
- 有相应的设备设施
- 有相应的管理人员

**申请机构**: 当地新闻出版局

## 七、合规注意事项

### 7.1 备案信息真实性

- 备案信息必须真实、准确、完整
- 不得提供虚假材料
- 备案信息变更时必须及时更新
- 定期核验备案信息（一般每年一次）

### 7.2 网站内容合规

- 不得发布违法违规内容
- 不得发布虚假广告
- 不得侵犯他人知识产权
- 不得泄露用户隐私
- 遵守《网络安全法》、《电子商务法》等法律法规

### 7.3 经营资质合规

- 按照经营范围开展业务
- 不得超范围经营
- 需要专项许可的商品必须取得相应资质
- 定期检查资质有效期，及时续期

### 7.4 税务合规

- 依法申报纳税
- 向用户提供发票
- 代扣代缴个人所得税（如需要）
- 保存财务记录至少5年

## 八、常见问题

### Q1: 不备案可以吗？
A: 不可以。所有在中国境内服务器上运行的网站都必须进行ICP备案，未备案的网站会被关闭。

### Q2: 经营性ICP许可证必须办理吗？
A: 如果涉及在线交易和有偿服务，建议办理。虽然目前监管不是100%严格，但存在被处罚的风险。

### Q3: 备案期间网站可以用海外服务器吗？
A: 可以。如果使用海外服务器，不需要ICP备案，但访问速度会受到影响。建议先备案，备案完成后再切换到国内服务器。

### Q4: 一个公司可以备案多个网站吗？
A: 可以。一个公司可以备案多个网站，每个网站需要单独备案。

### Q5: 备案号可以转让吗？
A: 不可以。备案号与备案主体绑定，不能转让。如果公司变更，需要办理备案变更手续。

### Q6: 食品经营许可证可以在网上销售食品吗？
A: 可以。取得食品经营许可证后，可以在网上销售预包装食品。销售保健食品需要在许可证中增加"保健食品销售"项目。

### Q7: 医疗器械可以在网上销售吗？
A: 可以，但需要取得医疗器械经营许可证（第二类、第三类）或备案（第一类）。同时需要遵守《医疗器械网络销售监督管理办法》。
