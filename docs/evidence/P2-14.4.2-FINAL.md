## 2. Key Features

**Real Screenshot:**
- Loads `screenshots/native_test.bmp`
- Uses StretchBlt to scale into VISION panel
- 2560x1440 → 200x100 display area

**Buttons:**
- START → state=RUNNING, event logged
- APPROVE → permission=APPROVED, event logged
- STOP → state=STOPPED, event logged
- All via WM_LBUTTONDOWN hit testing

**Timer Refresh:**
- WM_TIMER every 1 second
- Invalidates window → WM_PAINT redraw
