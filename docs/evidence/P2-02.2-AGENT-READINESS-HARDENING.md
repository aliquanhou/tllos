## 4. Phase 3: Agent Entry Protocol

**Result:** ✅ CREATED

新增文件：`tllos/agents/agent_entry_protocol.json`

内容：
- Boot Sequence（6 步）：
  1. read_genesis — 读取 Genesis，确认这是 TLL OS
  2. verify_manifest — 验证 Canonical Layer 完整性
  3. read_truth — 读取 Truth Layer，理解架构和已知限制
  4. read_contract — 读取 Agent Contract，理解权利义务
  5. declare_capability — 声明 Agent 角色和能力
  6. request_task — 接收施工令，开始执行任务
- 3 种 Agent 类型：developer / architect / owner
- Entry Requirements（必须完成 + 禁止事项）
- Verification Protocol（持续验证要求）
- Exit Protocol（退出要求）
