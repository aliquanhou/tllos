## 1. Architecture Change

**Before (P2-14.2):**
```
Python → PySide6 → Qt → Windows API
         (GUI dependency)
```

**After (P2-14.3):**
```
Python (glue) → ctypes → user32.dll / gdi32.dll → Windows API
                (native boundary)
```
