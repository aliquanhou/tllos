## 2. Phase 1: Permission Model Design ✅

**新增文件：**
- `tllos/agent_runtime/permission/permission_model.md` — 权限模型说明
- `tllos/agent_runtime/permission/permission_policy.json` — 权限策略
- `tllos/agent_runtime/permission/permission_schema.json` — 权限 Schema

**三状态机：**
```
requested → approved → executed
    ↓          ↓          ↓
 rejected   revoked    expired
```

**核心原则：**
- Agent 不能自行将 requested → approved
- Agent 不能自行将 approved → executed
- 无 approved 状态下不能执行任务
- 默认无权限，最小权限原则

## 3. Phase 2: Capability-Permission Map ✅

**新增文件：**
- `tllos/agent_runtime/permission/capability_permission_map.json`

**核心原则：Capability ≠ Permission**

| 错误示例 | 正确示例 |
|---------|---------|
| capability: filesystem → permission: write_all | capability: read_project_file → permission: project/read |
