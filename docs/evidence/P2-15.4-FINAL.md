## 1. What Changed

**Before (P2-15.3):**
```
Desktop Surface = one canvas
```

**After (P2-15.4):**
```
TLL Desktop
  ├── Window 1: Agent 控制台
  ├── Window 2: 任务空间
  └── Window 3: 状态面板

TLLWindowManager
  ├── create_window()
  ├── destroy_window()
  ├── move_window()
  ├── resize_window()
  └── focus_window()

TLLCompositor
  └── composite() → window buffers → desktop framebuffer
```

## 2. Window Object

| Field | Type | Description |
|-------|------|-------------|
| id | str | Unique window ID |
| title | str | Window title |
| x, y | int | Position on desktop |
| width, height | int | Window size |
| z_index | int | Z-order (stacking) |
| buffer | numpy | Window pixel buffer |
| state | str | NORMAL / MINIMIZED / MAXIMIZED |
