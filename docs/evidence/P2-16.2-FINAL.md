## 2. Real Subsystems

### TLLVirtualFileSystem
- In-memory file system
- read_file() / write_file() / list_dir() / delete_file()
- File metadata (size, created_at, modified_at)

### TLLProcessManager
- Real process lifecycle
- start_process() / stop_process() / list_processes()
- Kernel process always running
- Memory tracking per process

### TLLCodeRuntime
- Template-based code generation
- Safe sandboxed execution
- Output extraction from print statements
- Execution history tracking

### TLLAppRuntime
- Real application lifecycle
- create_app() / launch_app() / close_app()
- App → Window integration
- App → Process integration
