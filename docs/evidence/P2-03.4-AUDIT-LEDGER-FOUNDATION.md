- AgentRegistered
- CapabilityDeclared
- PermissionRequested

- PermissionDenied
- TaskCreated
- ExecutionRequested
- ExecutionCompleted
- ExecutionFailed
- EvidenceGenerated
- TaskRejected
- AuditReviewed

**关键字段：** event_id, event_type, agent_id, task_id, capability, permission, action, evidence_ref, status, timestamp

## 4. Phase 3: Ledger Record Schema ✅

**新增文件：** `tllos/agent_runtime/audit_ledger/ledger_record.json`

**核心字段：** ledger_id, event_id, agent_id, task_id, previous_record, evidence_ref, integrity, status

**重要说明：**
- previous_record 只是逻辑引用，不是区块链
- integrity 只是逻辑完整性，不是密码学完整性

---

## 5. Phase 4: Evidence Binding Protocol ✅

**新增文件：** `tllos/agent_runtime/audit_ledger/evidence_binding.md`

**完整闭环：**
```
Task Contract → Execution Request → Action → Evidence → Ledger Record → Audit
```

**禁止模式：**
1. ❌ Task Completed but no Evidence
2. ❌ Action Recorded but no Task
3. ❌ ExecutionCompleted but no evidence_ref
4. ❌ ExecutionRequested but no permission
