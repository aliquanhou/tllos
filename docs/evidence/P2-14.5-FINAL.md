## 1. Runtime Binding Architecture

```
Human Click
    ↓
WM_LBUTTONDOWN
    ↓
Lifecycle Controller (state machine)
    ↓
Valid Transition?
    ├─ YES → Update State → Event Log → InvalidateRect
    └─ NO  → REJECTED → Event Log → No change
    ↓
WM_TIMER (1s)
    ↓
StateBus.refresh() → reads agent_state.json
    ↓
InvalidateRect → WM_PAINT → GDI Redraw
```

## 2. Key Components

**State Bus:**
- Reads `tllos/agent_runtime/lifecycle/agent_state.json`
- Displays: Goal, Confidence, Plan Steps, Permission
- Fallback: placeholder if file doesn't exist

**Lifecycle Controller:**
- Valid transitions: IDLE → CREATED → OBSERVING → THINKING → PLANNING → WAIT_APPROVAL → EXECUTING → VERIFYING → COMPLETED
- Invalid transitions REJECTED
- Event log records all transitions

**Frame Buffer:**
- Loads `screenshots/native_test.bmp`
- SHA256 hash: `0f6437a894ffd86a...`
- Displays hash + timestamp in VISION panel

**Monitor-2 Support:**
- Detects monitor count via GetSystemMetrics(SM_CMONITORS)
- Moves window to monitor 2 if available
- Currently: 1 monitor detected (C32JG5x)
