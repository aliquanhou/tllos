| 跨平台 | Windows + Linux | ✅ |

### 2.2 语言已知限制（有替代方案）

| 限制 | 影响 | 替代方案 |
|------|------|---------|
| 三元运算符 ?: | 代码编写 | if/else 替代 |
| 反引号模板字符串 | 字符串拼接 | + 拼接 |
| type 保留字 | 变量命名 | 用 kind/category 替代 |
| 闭包捕获变量多线程 | 并发安全 | req.db 注入 + 全局函数 |
| strings.toLowerCase 运行时问题 | 大小写处理 | 硬编码多种变体 |
| 大 CSS 字符串多线程内存 | 内存安全 | 拆分 CSS / 外部文件 |
