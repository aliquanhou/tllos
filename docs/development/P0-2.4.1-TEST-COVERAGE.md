## Coverage Philosophy

Per P0-2.4.1 directive: "Do not force every test to have a snapshot."

- **Exit code = 100% coverage** (mandatory for all tests)
- **Stdout = targeted coverage** (only for tests with deterministic, environment-independent output)
- **Stderr** — not yet implemented (`.expected.err.txt` convention reserved for future)
