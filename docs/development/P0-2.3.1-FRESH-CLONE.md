# P0-2.3.1 — Fresh Clone Developer Experience

**Date:** 2026-08-27
**Tag:** TLL-OS-P0-2.3.1
**Previous:** TLL-OS-P0-2.3 (tllc CLI)

## Problem

After P0-2.3 merged tllc CLI into main, the repository was not usable from a fresh clone:

1. CI directly executed `tests/acceptance/01_hello.tllbc`, but `*.tllbc` is globally gitignored (only `compiler/compiler.tllbc` and `runtime/vm_run.tllbc` are tracked). Fresh clone had no test bytecode.
2. No build scripts — developers had to manually compile `tllvm` with gcc/clang/MSVC commands.
3. No way to bootstrap `tllc.tllbc` from source — it was gitignored but not regeneratable via script.
4. README Quick Start referenced `01_hello.tllbc` which doesn't exist after clone.
5. AGENT.md had outdated seed SHA256 and inaccurate test artifact descriptions.

## Solution

Added a complete fresh-clone developer toolchain:

### Build Scripts
- `scripts/build.bat` — Windows: extracts bundled `host/c/tcc.zip`, compiles `tllvm.exe`
- `scripts/build.sh` — Linux/macOS: compiles `tllvm` with gcc/clang

### tllc Bootstrap
- `compiler/bootstrap_tllc.tll` — Pre-defined compiler entry with `main()` that compiles `tools/TLLC/main.tll` instead of self-hosting
- `scripts/bootstrap-tllc.bat` / `.sh` — Two-stage bootstrap:
  1. Swap `compiler.tll` with `bootstrap_tllc.tll`
  2. Seed compiler compiles bootstrap entry → `compiler_self_compiled.tllbc`
  3. Bootstrap compiler compiles tllc → `tools/TLLC/tllc.tllbc`
  4. Restore original `compiler.tll`

### Test Scripts
- `scripts/compile-tests.bat` / `.sh` — Compiles all acceptance + regression `.tll` files to `.tllbc` using tllc
- `scripts/run-tests.bat` / `.sh` — Runs all compiled tests, reports pass/fail counts

### CI Fix
- `.github/workflows/ci.yml` rewritten to:
  1. Build `tllvm` from C source
  2. Verify bootstrap seeds exist
  3. Native self-host verification
  4. Bootstrap tllc
  5. Compile all tests from source
  6. Run all tests
  7. End-to-end: tllc compile hello.tll → tllvm execute

### Documentation
- `README.md` — Rewrote Quick Start with 4-step fresh clone workflow, tllc command reference, updated project structure
- `AGENT.md` — Updated seed SHA256 to `1D1AC4CBE9B6A943B500F6DA0B2D41495C0A9026ACF98378B89EE5460189746B`, added fresh clone workflow, tllc usage, scripts directory, corrected test artifact description

### Test Fix
- `tests/regression/test_process.tll` — Changed `process.exit(42)` to `process.exit(0)` so automated test runner doesn't misreport failure. Exit code propagation was already verified in P0-2.2.

## Known Limitations

- `scripts/build.bat` has a cosmetic bug: prints an empty "Size:  bytes" line before the actual size. Does not affect functionality.
- CI on Windows uses MSVC `cl`; code may have MSVC-specific compatibility issues not caught by local TCC builds.
- No standalone `tllc` wrapper binary yet — must invoke via `tllvm tools/TLLC/tllc.tllbc <command>`.
- Test runner only checks exit code (0 = pass), does not compare output against expected files.
