# P0-2.2: Process API (argv + exit)

**Date**: 2026-08-26
**Branch**: feature/process-api
**Status**: COMPLETED

## 问题

TLL v1.1 缺少操作系统交互能力：
- 无法获取命令行参数（process.argv）
- 无法设置进程退出码（process.exit）

这导致无法编写真正的 CLI 工具，是 tllc 项目的前置阻塞。

## 复现

```tll
fn main() {
    let argv = process.argv  // ReferenceError: process is not defined
    process.exit(1)          // ReferenceError: process is not defined
}
```

## 根因

1. **C 层缺失**：builtin 表中没有 process 模块，main.c 没有保存 argc/argv
2. **TLL 层缺失**：codegen.tll 没有 process builtin 索引，linker.tll 不识别 process 为 stdlib 模块
3. **Codegen Bug**：process.argv 是属性访问，首次实现时仅编译为 OP_LOAD_BUILTIN（加载函数值），没有调用它，导致 argv 得到 builtin 函数值而非数组

## 修改

### C 层 (host/c/)

| 文件 | 修改 |
|------|------|
| tllvm.h | 添加 extern 声明：tll_argc, tll_argv, tll_exit_code, tll_should_exit |
| main.c | 定义全局变量，main() 中保存 argc/argv，返回 tll_exit_code |
| vm.c | 主循环检查 tll_should_exit，支持提前退出 |
| builtin.c | 添加 builtin 120 (process.exit) 和 121 (process.argv) |

### TLL 层 (compiler/)

| 文件 | 修改 |
|------|------|
| codegen.tll | cg_getBuiltinIndex 添加 process.exit→120；Member 表达式特殊处理 process.argv→加载 builtin 121 后立即调用（0 参数） |
| linker.tll | isStdlibModule 添加 "process" |

### Builtin 索引分配

| 索引 | 名称 | 说明 |
|------|------|------|
| 120 | process.exit(code) | 设置退出码，标记 VM 提前退出 |
| 121 | process.argv | 返回命令行参数数组（含程序名） |

## 已知限制

1. process.argv 包含完整参数列表（argv[0] 是 tllvm.exe 路径，argv[1] 是 .tllbc 路径），用户程序参数从 argv[2] 开始
2. process.exit 不执行 VM cleanup（当前架构下 program/constants 故意不释放）
3. 尚未实现 process.env（计划 P0-2.4）
4. 尚未实现 process.exec（计划 P0-2.6）
