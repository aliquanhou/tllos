# P0-15.18.6 Performance Benchmark Report

## 概述

P0-15.18.6 建立 TLL Runtime 核心操作的性能基准，覆盖 Coroutine、JSON、Blockchain 三大领域。

## 测试设计

### 测试 1: Coroutine 性能
- **创建吞吐量**: 10,000 个 coroutine 创建+完成
- **Yield/Resume 吞吐量**: 1,000 coroutine × 100 yields = 100,000 次 yield/resume
- **Sleep 调度**: 1,000 个 sleep(50ms) coroutine

### 测试 2: JSON 序列化性能
- **简单对象**: 1,000 次 round-trip（serialize + deserialize）
- **嵌套对象**: 100 次 round-trip
- **大数组**: 100 次（100 元素数组）round-trip

### 测试 3: Blockchain 核心操作性能
- **Transaction 创建+签名**: 1,000 笔
- **Merkle Root 计算**: 100 个（每区块 10 tx）
- **Block Hash 计算**: 1,000 次
- **完整挖矿**: 10 区块（每区块 5 tx，difficulty=1）

## 测试结果（本地 Windows MSVC）

### Coroutine 性能
| 指标 | 数值 | 备注 |
|------|------|------|
| Coroutine 创建 | 95.4 μs/个 | 10,000 个耗时 954ms |
| Yield/Resume | 2.19 μs/次 | 100,000 次耗时 219ms |
| Sleep 调度 | 0.111 ms/个 | 1,000 个 sleep(50ms) 耗时 111ms |

**结论**: Coroutine 创建和调度性能良好，sleep 调度高效（1000 个 50ms sleep 仅用 111ms，说明并发调度正常）。

### JSON 序列化性能
| 指标 | 数值 | 备注 |
|------|------|------|
| 简单对象 | 5 μs/次 | 1,000 次耗时 5ms |
| 嵌套对象 | 10 μs/次 | 100 次耗时 1ms |
| 大数组(100元素) | 420 μs/次 | 100 次耗时 42ms |

**结论**: JSON 序列化性能良好，简单对象 5μs，大数组随元素数量线性增长。

### Blockchain 核心操作性能
| 指标 | 数值 | 备注 |
|------|------|------|
| Transaction 创建+签名 | 2.6 ms/笔 | 1,000 笔耗时 2605ms（HMAC-SHA256） |
| Merkle Root 计算 | 0.01 ms/个 | 100 个耗时 1ms（10 tx/区块） |
| Block Hash 计算 | 0.001 ms/次 | 1,000 次耗时 1ms |
| 完整挖矿(diff=1) | 143 ms/块 | 10 区块耗时 1429ms（5 tx/块） |

**结论**: Blockchain 核心操作性能良好。Transaction 签名是瓶颈（2.6ms/笔，因为 HMAC-SHA256），但符合预期。Merkle 和 Hash 计算极快。

## 性能分析

### 优势
1. **Coroutine 调度高效**: 1000 个 50ms sleep 仅用 111ms，说明 IO-aware scheduler 正常工作
2. **JSON 序列化快速**: 简单对象 5μs，适合高频使用
3. **Hash/Merkle 计算极快**: 0.001-0.01ms，不是瓶颈

### 瓶颈
1. **Transaction 签名**: 2.6ms/笔，主要消耗在 HMAC-SHA256
   - 当前是模拟签名（HMAC），未来引入真实 Ed25519 后可能更慢
   - 高吞吐场景（>1000 tx/s）需要优化

2. **完整挖矿**: 143ms/块（diff=1）
   - 主要消耗在 PoW 循环（SHA256 反复计算）
   - difficulty=1 时平均 16 次 hash 计算
   - 更高 difficulty 会线性增长

### 可优化方向
1. SHA256 实现优化（当前是纯 TLL 实现，可用 C 原生加速）
2. Transaction 签名批处理
3. Merkle Root 并行计算
4. JSON 序列化缓存

## 结论

P0-15.18.6 Performance Benchmark **PASS**

- 三大领域（Coroutine/JSON/Blockchain）性能基准已建立
- 所有测试在三平台 CI 通过
- 性能数据符合预期，无异常瓶颈
- 已识别可优化方向（SHA256 加速、签名批处理）

## 已知限制

- 性能数据基于本地开发机，CI runner 性能可能不同
- 未做长时间性能衰减测试（内存碎片、GC 影响）
- 未测试高并发场景（>10K 并发 coroutine）
- 当前签名是 HMAC 模拟，真实加密签名性能未知
