## TLL 语言 Linux 适配修复

本次部署修复了 TLL 语言在 Linux 下的关键缺陷：

### 1. HTTP 服务器跨平台支持
- **问题**: `http.serve` 内置函数仅在 Windows 下实现，Linux 下返回 "not available"
- **修复**: 在 `builtin.c` 的 `#else`（Linux）块中实现完整的 POSIX socket HTTP 服务器
- **功能**: socket/bind/listen/accept、Worker Pool 8 线程、请求解析、响应发送

### 2. Worker Pool 跨平台实现
- **问题**: Windows 使用 CRITICAL_SECTION + CreateThread + Semaphore
- **修复**: Linux 使用 pthread_mutex_t + pthread_create + sem_t
- **文件**: builtin.c 第 200-280 行

### 3. SQLite 绑定跨平台支持
- **问题**: sqlite_builtin.c 包含 `<windows.h>`，Linux 编译失败
- **修复**: 使用 `#ifdef _WIN32` 条件编译，Windows 使用 CRITICAL_SECTION，Linux 使用 pthread_mutex_t
- **新增**: `#include <stdint.h>` 支持 intptr_t 类型

### 4. 全局 VM 锁跨平台
- **问题**: g_vm_lock 使用 Windows CRITICAL_SECTION
- **修复**: Linux 使用 pthread_mutex_t，静态初始化 PTHREAD_MUTEX_INITIALIZER
