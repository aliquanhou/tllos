# TLL OS Grounded Agent Loop

## Purpose

Closed-loop agent: Observe → Think → Plan → Act → Verify → Reflect

---

## Loop Flow

```
1. OBSERVE
   Capture screen → Objects → Context
     ↓
2. THINK
   Reason about goal → Options → Decision
     ↓
3. PLAN
   Decompose goal → Steps → Order
     ↓
4. ACT
   Permission Gate → Execute action
     ↓
5. VERIFY
   Compare expected vs actual
     ↓
6. REFLECT
   Success? → Continue / Retry / Improve
     ↓
   (loop back to 1)
```

---

## Recovery Loop

```
Action Failed
  ↓
Reflect: Why?
  ↓
Reason Alternative
  ↓
Replan
  ↓
Retry (max 2)
```
