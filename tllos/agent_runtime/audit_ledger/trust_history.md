# TLL OS Trust History

## 信任历史

基于 Audit Ledger 记录的 Agent 行为历史，评估 Agent 的信任度。

## 信任维度

| 维度 | 说明 |
|------|------|
| 可靠性 | Agent 是否按承诺完成任务 |
| 诚实性 | Agent 是否如实报告 Evidence |
| 合规性 | Agent 是否遵守 Permission 和 Scope |
| 效率 | Agent 完成任务的质量和速度 |
| 一致性 | Agent 的行为是否可预测 |

## 信任评分（未来）

**当前：** 只记录事件，不计算评分

**未来：**
- 基于历史事件计算信任分
- 基于违规记录降级
- 基于长期合规升级

## 信任生命周期

```
新 Agent（低信任）
  ↓
完成几个任务（信任提升）
  ↓
长期合规（信任稳定）
  ↓
发现违规（信任下降）
  ↓
持续违规（信任吊销）
```

## 用途

1. **新任务分配** — 优先分配给高信任 Agent
2. **权限审批** — 高信任 Agent 自动审批
3. **异常检测** — 发现行为模式异常
4. **审计追溯** — 回溯 Agent 历史行为
